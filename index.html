What is Potato Savior?

A little help for PCs that are fighting for their lives.

Potato Savior is a Minecraft modpack created to improve performance using a collection of optimization, memory, rendering and quality-of-life mods.


The goal is simple: help more players enjoy Minecraft, even on older hardware. No expensive PC required.

How to install

Get your potato ready in a few simple steps.

  1. Download the ZIP. Use the download button at the top of this page.
  2. Install Minecraft 1.16.5 and Fabric. Use a compatible Fabric Loader version.
  3. Install the mods. Follow the included pack instructions and ensure all required mod files match Minecraft 1.16.5.
  4. Launch and play! Start Minecraft using your Fabric installation.
Important: check the included README for the exact installation method and requirements. Back up existing worlds before changing mod setups.
